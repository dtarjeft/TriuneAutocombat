This folder holds the log files Triune AutoCombat (TAC) writes: the main log (triune_<server>_<character>.log),
/ac dump files, and the Chat Windows plugin logs (tac_chat_*).

It is shipped with TAC so it exists after you extract the release into your MacroQuest folder. TAC also creates it
if it is missing. You can delete the log files here; TAC makes new ones. Keep this file or not, TAC does not need it.
